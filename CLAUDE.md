# spill

"Hvor er hytta?", et enkelt nettleserspill som ansatte i DNT Oslo og Omegn lager sammen, for ansatte. Spilleren får hint eller bilde av en DNT-hytte og skal peke den ut på kartet, og jo nærmere treffet er, jo flere poeng. Flere bidrar, også folk som er nye på koding og KI-verktøy.

## Utvikling

- Ren HTML, CSS og JavaScript uten byggverktøy, så alle kan endre en fil og se resultatet direkte i nettleseren.
- Spillet publiseres med GitHub Pages.

## Hyttedata og bilder

- Spillet har bare med hytter som DNT Oslo og Omegn både eier og driver, ikke andre foreningers hytter eller hytter vi bare driver for andre.
- Hytteinformasjon og bilder hentes fra ut.no, og vi har lov til å bruke dem i spillet.
- Vis alltid fotografens navn sammen med bilder fra ut.no.

## Repoet er public

Alt som committes kan leses av hvem som helst på internett, og ligger igjen i git-historikken selv om det slettes senere.

- Ikke commit personopplysninger om medlemmer, deltakere, frivillige eller kollegaer, som navn, e-post, telefonnummer eller bilder av folk.
- Ikke commit hemmeligheter som API-nøkler, passord eller tokens. Legg dem i en `.env`-fil som står i `.gitignore`.
- Ikke legg inn interne dokumenter, økonomitall, interne lenker eller annet som ikke er ment for offentligheten.
- Annen grafikk og lyd enn ut.no-bilder må vi ha rett til å publisere. DNT-logoen har egne regler, så spør før den brukes.
- Er du usikker på om noe kan ligge åpent, si fra til brukeren før du committer.
